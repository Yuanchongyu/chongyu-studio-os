Phase 1 · Dataset / Label

Dataset 是 AI 的教材和题库

三个最小概念

D
Dataset
很多带答案的数据集合。
S
Sample
一条数据，比如一张 Ryan 的照片。
L
Label
这张照片的正确答案，比如 “Ryan”。
dataset/ ├── ryan/ │ ├── 01.jpg → Label: Ryan │ └── 02.jpg → Label: Ryan └── spencer/ ├── 01.jpg → Label: Spencer └── 02.jpg → Label: Spencer
Phase 1 · Train / Validation / Test / Inference

学习、模拟考试、上班

Training

模型看训练照片，猜答案，错了就调整。

学习 / 做练习

Validation

拿没参与训练的照片小测，检查它是否真的学会。

模拟考试

Inference

模型训练完后，面对摄像头里的新人脸进行判断。

真正上班
Overfitting：如果 AI 只是背下训练照片，而不是学会“什么是 Ryan / Spencer”，换个角度或光线就可能失败。
